# 🚀 GUIDE ULTRA-SIMPLE : Déployer ZYNO en 10 Minutes

## ⚡ Méthode Rapide - Via l'Application Web

### ÉTAPE 1️⃣ : Installer MetaMask (5 minutes)

**Si vous n'avez pas MetaMask :**

1. **Téléchargez** : https://metamask.io/download/
2. **Installez l'extension** dans votre navigateur (Chrome/Firefox)
3. **Créez un nouveau wallet** :
   - Cliquez sur "Créer un portefeuille"
   - Créez un mot de passe
   - **⚠️ IMPORTANT** : Notez votre phrase de 12 mots sur PAPIER et gardez-la en SÉCURITÉ
   - Ne partagez JAMAIS cette phrase !

---

### ÉTAPE 2️⃣ : Obtenir des Crypto pour Payer le Déploiement (3 minutes)

**Option A : Pour TESTER (Gratuit) - RECOMMANDÉ pour commencer**

Réseau : **Sepolia Testnet**

1. Dans MetaMask, changez de réseau :
   - Cliquez en haut à gauche
   - "Afficher les réseaux de test"
   - Sélectionnez "Sepolia"

2. Obtenez des tokens gratuits :
   - Allez sur : https://sepoliafaucet.com/
   - Collez votre adresse MetaMask
   - Cliquez "Send Me ETH"
   - Attendez 1 minute

✅ Vous avez maintenant des tokens de TEST pour déployer !

---

**Option B : Pour le VRAI Déploiement (Coûte de l'argent)**

Réseau : **Binance Smart Chain** (le moins cher)

1. Dans MetaMask, ajoutez BSC :
   - Paramètres > Réseaux > Ajouter un réseau
   - Ou cherchez "BSC" dans la liste

2. Achetez du BNB :
   - **Via Binance** : Achetez ~$10 de BNB, envoyez à votre adresse MetaMask
   - **Via MoonPay** (directement dans MetaMask) : Carte bancaire

---

### ÉTAPE 3️⃣ : Déployer le Token (2 minutes)

1. **Ouvrez l'application** : https://blockchain-maker-1.preview.emergentagent.com

2. **Cliquez sur "🦊 Connect MetaMask"** en haut à droite
   - Une popup MetaMask apparaît
   - Cliquez "Suivant" puis "Connecter"

3. **Allez sur la page "Deploy"** (menu du haut)

4. **Vérifiez les informations** :
   ```
   Nom : Zyno
   Symbole : ZYN
   Supply Initial : 100,000,000
   Supply Max : 500,000,000
   ```

5. **Cliquez sur "🚀 Déployer le Token"**

6. **MetaMask s'ouvre** :
   - Vérifiez les frais
   - Cliquez "Confirmer"

7. **Attendez 10-30 secondes** ⏳

8. **✅ C'EST FAIT !** L'adresse du contrat s'affiche à l'écran

9. **COPIEZ L'ADRESSE** et sauvegardez-la quelque part !

---

## 📋 Après le Déploiement

### Ajouter ZYNO à MetaMask

1. Dans MetaMask, cliquez "Importer des tokens"
2. Collez l'adresse du contrat
3. Le reste se remplit automatiquement
4. Cliquez "Ajouter"

### Mint vos 400M Tokens

1. Sur l'application, allez sur "Manage"
2. Onglet "Mint"
3. Entrez :
   - **Adresse** : Votre adresse MetaMask
   - **Montant** : 400000000
4. Cliquez "Mint"
5. Confirmez dans MetaMask

---

## ❓ Problèmes Courants

### "Insufficient funds"
➡️ Vous n'avez pas assez de crypto dans votre wallet
- Pour Sepolia : Retournez sur le faucet
- Pour BSC : Achetez plus de BNB

### "Transaction failed"
➡️ Augmentez les "Gas fees" dans MetaMask
- Avant de confirmer, cliquez "Modifier"
- Augmentez un peu les frais

### "User rejected transaction"
➡️ Vous avez cliqué "Annuler" dans MetaMask
- Recommencez et cliquez "Confirmer"
